# 一维平板单群扩散特征值常驻后端

把"多区平板、裸板/外推/全反射边界、源迭代求 k_eff"的手算过程做成常驻 HTTP 服务：
工况可存可改、结果按参数版本留档、临界搜索异步执行；燃料区可声明燃耗参数，
燃耗历程挂在某一版参数上后台推进——学员能看到一炉燃料从新装到烧不动的
全过程，以及通量形状怎么跟着变。

- 内核：1D slab、单群、扩散方程 `-d/dx(D dφ/dx) + Σa φ = (1/k) νΣf φ`
- 离散：有限体积（守恒型），界面净流 `-D dφ/dx` 天然连续；**不在区界面上平均截面**
- 三对角求解（Thomas）、源迭代、二分求根全部手写；NumPy 仅用于数组运算
- 工况 / 参数版本 / 结果版本化持久化（卷挂目录即可保留）
- 临界搜索为异步作业，可查进度、可取消，作业锁定提交时刻的参数版本
- 燃耗：逐单元空间分辨消耗、预估-校正二阶时间推进、恒定总裂变率运行；
  历程可分段推进、可取消、重启可续，每个时间点单独取回

## 热启动策略（交付说明）

### 选了什么

- **初值**：把上一版收敛通量按新网格单元中心做**分段线性重映**
  （`interpolation.py`，手写），新坐标落在旧网格外用边界值外延；
  同时**继承上一版的 k**。热启动只继承形状不继承 k 时，右端 `(1/k)Fφ`
  与形状不匹配，实测反而比冷启动慢。
- **迭代**：热启动不用裸源迭代，而用 **Wielandt 逆移位（逆幂）加速**——
  每步取移位 `p = 1.01·k̂`（在当前 k 估计上方，使 `M−F/p` 正定、基模占优），
  解 `(M−F/p)ψ = Fφ`，归一后用广义 Rayleigh 商
  `k̂ = <Fψ,ψ>/<Mψ,ψ>` 重估 k。
  当改动很大、新 k 越过移位点（解出负值/非有限，或移位矩阵遇零主元）时，
  该步自动退回一杆普通源迭代，保证永远朝基模、永不出负通量。
- **判据**：k 与通量形状**两个都看**——
  `|Δk|/k < k_tol` 且 `‖φⁿ⁺¹−φⁿ‖₂/‖φⁿ⁺¹‖₂ < flux_tol` 才停。
  形状用归一化后的裂变源形状（即归一化通量本身）。

### 为什么这么选（真实取舍）

1. **为什么必须双判据，不能只看 k。** 源迭代里 k 比形状收敛快：
   形状里残留高阶模时，Rayleigh 型 k 更新可以先到位。只看 k 会"带着
   旧形状提前停下"，这正是热启动最容易踩的坑（旧通量本身就带着旧问题的
   形状偏差）。代价是每步多算一个 L2 差（O(M)，可忽略），多走若干步。
2. **为什么不用裸源迭代做热启动。** 平板扩散源迭代的形状收敛因子
   `ρ = λ₂/λ₁`（以 `M⁻¹F` 的特征值计）。基准裸板（a=50, D=1, Σa=0.1）
   ρ≈0.904，压到 1e-9 要 ~190 次形状更新；平坦冷启动因为高阶成分在
   前几步衰减快，常在 ~70 步过门，而热启动初值更"干净"、没有这部分
   快速衰减红利，逐次差又在 1e-10 舍入平台附近抖动，实测**更慢且不稳**。
   Wielandt 移位把高阶模比压到
   `(λ₂−λ₁)/(p−λ₁)` 量级，"改动越小、旧 k 越靠近新 k"时收益越大，
   正好契合"改某个区再算"的使用模式；它比 Chebyshev/多步外推简单、
   自校正、不会过头发散。
3. **判据松/严的权衡。** 双判据默认都取 1e-9：松到 1e-6 能再省几步，
   但冷热两条路径的 k 差就不再稳定地落在容差量级内、通量形状也会
   系统性差一截（被 `test_hot_cold` 抓到）；严到 1e-12 则逼近逐次差的
   舍入平台（~1e-10），步数虚高且残差抖动。1e-9 是这台问题上
   "结果可信"与"省步"的折中点；容差随工况可调。
4. **为什么是线性重映而不是外推几步再起步。** 改厚度/网格后，旧网格
   与新网格只是采样位置不同，线性重映得到的形状已经非常接近新基模；
   在旧解上做几步"外推加速"既依赖旧算子、又可能把旧问题的高阶误差
   放大，收益不稳。重映 + 移位逆幂这一组合对"改厚度/截面/加密"都鲁棒，
   大改动时退回普通迭代，结果始终与冷启动一致。

### 同一改动下冷、热两条路径的迭代次数（默认容差 1e-9，实测）

| 改动（在 a=50、100 网格的裸板上） | 冷启动 | 热启动 | k 之差 |
|---|---:|---:|---:|
| 厚度 50→52 cm、网格 100→120 | 75 | **9** | 2.6e-10 |
| 仅加密网格 50→100 | 70 | **4** | <1e-9 |
| νΣf 0.120→0.125 | 70 | **3** | <1e-9 |
| 大改：厚度 50→100、网格 100→200 | 228 | **17** | 2.9e-10 |

`pytest tests/test_hot_cold.py -s` 会打印这张表并断言冷热 k 差 <1e-7、
归一化通量形状差 <1e-6、两条路径中子平衡都 <1e-8。

## 燃耗（交付说明）

### 物理口径

燃料区可额外声明（`region.burnup`，三个量必须一起给）：

| 字段 | 含义 | 约束 |
|---|---|---|
| `fissile_density_0` | 易裂变核素初始数密度 N0（10²⁴ cm⁻³） | > 0 |
| `sigma_a_micro` | 易裂变核素微观吸收截面（barn） | ≥ 0（为 0 即不消耗） |
| `fissile_absorption_fraction` | 该区 Σa 中来自易裂变核素的份额 f | ∈ [0, 1] |

未声明的区不燃耗，参数始终不变。燃耗期间消耗率正比于当地通量与当地
剩余数密度：`dN/dt = −σa·φ·N`；νΣf 与 Σa 的易裂变部分按 N/N0 同步缩小，
Σa 其余部分与 D 不变。全程恒定总裂变率：每个时刻通量都归一到工况给定
的 `target_total_fission`，燃料越烧、通量幅值越高。

### 空间分辨：从第一步起"一区一套截面"就不再成立

通量中间高、边缘低，同一区里中心烧得快、边缘烧得慢。因此燃耗状态是
**逐单元**剩余份额 `r_i = N_i/N0`，每个时间步按它重算**逐单元**截面：

```
νΣf_i(t) = νΣf_i,0 · r_i        Σa_i(t) = Σa_i,0·(1−f) + Σa_i,0·f·r_i
```

Mesh 本来就逐单元存 Σa/νΣf（界面从不平均截面），所以离散、Thomas 求解、
逐区反应率统计（`np.add.reduceat` 按区分组）和中子平衡望远镜恒等式全部
原样复用——燃耗只是给求解器换了一套逐单元系数。数密度以比值 r 跟踪：
`dN/dt = −σφN` 对 N 线性，N0 在比值中约去（绝对数密度 N0·r_i 可随时还原），
声明中的 N0 参与校验并随快照存档。各区剩余份额按体积加权（= 区内剩余
原子数/初始原子数）上报。

### 时间推进格式的选择（三选一，实现的是预估-校正）

单个时间步里通量与数密度的耦合，候选方案：

1. **步首通量一用到底（显式 Euler）**：`rⁿ⁺¹ = rⁿ·exp(−σ̃φⁿΔt)`。每步只
   1 次特征值求解，最便宜；但只有一阶，误差 O(Δt)——步长减半误差才减半。
   燃耗演示要看"从新装到烧不动"的长历程（几十上百步），一阶格式把误差
   压下去只能靠缩步长，步数（=求解次数）成倍增加。
2. **子步细分**：把一步拆成 m 个子步，子步内仍用步首通量。本质上还是
   一阶（误差常数缩小 ~1/m），多一个子步数旋钮；同样的求解次数预算下
   不如直接上二阶格式。
3. **预估-校正（Heun 二阶，本服务采用）**：
   ```
   预估  r^p  = rⁿ·exp(−σ̃·φⁿ·Δt)          在 r^p 上解出 φ^p
   校正  rⁿ⁺¹ = rⁿ·exp(−σ̃·(φⁿ+φ^p)/2·Δt)  在 rⁿ⁺¹ 上解出该点的 k 与通量
   ```
   其中 `σ̃ = σa·1e-24·86400`（barn→cm²、秒→天）。对 `∫φdt` 这是梯形
   估计，局部误差 O(Δt³)、**全局 O(Δt²)**。指数积分器严格保持
   r ∈ (0,1]（份额永不为负、永不超过 1），通量非负由求解器保证。

**为什么选 3**：同样把误差压到 ε，二阶格式需要的步数 ~ ε^(−1/2)，一阶
需要 ~ ε^(−1)。以实测为例（σa=500 barn、F=5e15、40 cm 全反射板）：
Δt=1 天推 10 步，k 对手推值的偏差 2.9e-5；显式 Euler 要达到同一精度
需把步长缩到 ~0.03 天（约 330 步、330 次求解），预估-校正只要 10 步、
20 次求解。**代价**：每步 2 次特征值求解（预估态一次、校正后的步末态
一次），比显式贵一倍；但燃耗步之间状态变化小，热启动（Wielandt）每次
求解只需几步迭代，实测每步总开销约 0.5 ms（60 网格），远小于 2 个冷
启动。预估态的解只用于构造平均通量，不留档。

**步长减半时误差怎么缩**：全局误差 ~ C·Δt²，减半后约变为 **1/4**。
实测（同一 0D 基准，t=10 天处 k 对手推值的偏差）：

| Δt（天） | k 偏差 | 误差比 |
|---:|---:|---:|
| 2.0 | 1.14e-4 | — |
| 1.0 | 2.87e-5 | 3.98 |
| 0.5 | 7.19e-6 | 3.99 |
| 0.25 | 1.80e-6 | 4.00 |

`tests/test_burnup.py::test_error_shrinks_quadratically_when_step_halved`
断言误差比落在 (2.5, 6) 区间。

### 可手推的基准：两端全反射单区

两端全反射时 B=0、通量平，没有空间效应，燃耗可以手推到底。归一化
`νΣf(t)·φ(t)·a = F`（恒定总裂变率）给出 `φ(t) = F/(νΣf0·r(t)·a)`，于是

```
dr/dt = −σ̃·F/(νΣf0·a) ≡ −λ（常数）  →  r(t) = 1 − λt
k(t)  = νΣf0·r(t) / (Σa0·(1−f) + Σa0·f·r(t))
```

数值历程每个时间点都贴住这条曲线（上表即该基准），偏差随步长减半按
二阶缩小。`test_reflective_slab_tracks_hand_derived` 逐点对照。

### 历程、分段推进与一致性保证

- 一条历程在创建时**内嵌所挂参数版本的快照**（与临界搜索同一套版本
  锁定哲学）：工况随后被改、被删都不影响它；同一工况的不同版本可以
  各挂一条历程同时推进，时间点按历程 id 分文件存放，互不混入。
- 每个时间点算完立即落盘（先写点文件、再更新历程计数；崩溃只会留下
  一个未被引用的点文件，重启后按历程里的 `n_points` 续推，孤儿文件被
  同名下一次写入原子覆盖）。进度含已完成步数、当前燃耗时间、当前 k。
- **分段推进**：停下、被取消、甚至服务重启之后，`advance` 从最后一个
  已完成时间点继续。续推状态（逐单元剩余份额、通量、k）从该点的存档
  精确恢复——JSON 浮点按最短 repr 往返无损，推进算法完全确定，因此
  分段（4 步 + 重启 + 6 步）与一次性推 10 步的结果**逐位相同**
  （实测 Δk = 0、份额相对差 = 0），远优于"k 差在收敛容差量级、份额
  相对差 ≤ 1e-9"的要求。
- **取消**：工作线程在步间与写点前检查取消标志；已完成的点保留，
  未完成的步不写入，终态 cancelled，之后仍可续推。
- **耗尽**：恒定总裂变率下燃料烧尽时通量趋于无穷、特征值问题失去
  意义。历程在裂变权重归零前以 `exhausted` 终态干净停下（不是
  failed），已完成时间点全部保留且每个都平衡 < 1e-8——这就是
  "烧不动"的终点。
- 服务重启时仍在 queued/running 的历程标为 `interrupted`（不自动
  重跑），已完成点保留，可续推。

## 离散与边界条件

单元中心有限体积。单元 `i` 宽 `h_i`，单元中心存 φ_i；
界面 `i±1/2` 上的净流用调和平均传导率表示，跨界面只用一次同一个流，
因此 `-D dφ/dx` 逐界面严格连续，界面两侧各自的 D、Σa 从不做平均：

```
J_{i+1/2} = g_{i+1/2}(φ_i − φ_{i+1/1})
g = 2 D_i D_{i+1} / (D_i h_{i+1} + D_{i+1} h_i)
```

同区等距时 `g = D/h`，退化成标准中心差分。

三种外边界（左右独立）：

| 边界 | 含义 | 边界面传导率 |
|---|---|---|
| `zero_flux` | 物理面上 φ=0（裸板） | `g_b = 2D/h`（镜像零值点） |
| `extrapolated` | 外推距离 `2.13 D` 处 φ=0 | `g_b = D/(h/2 + 2.13D)` |
| `reflective` | 全反射（对称面），J=0 | `g_b = 0` |

## 中子平衡

每次求解返回每区吸收率 `Σa φ h`、裂变率 `νΣf φ h`（以及单独的左、右端泄漏率），
并报告平衡残差：

```
rel_balance = | Σfission/k − Σabsorption − (J_left + J_right) | / (Σfission/k)
```

守恒型离散下这是望远镜求和恒等式，要求 `< 1e-8`（热启动同样要过）。

## 裸板加密与外推边界口径

多级网格（25/50/100/200/400）实测误差比约 4、收敛阶 ≈ 2（四种边界组合
都是）。要注意一个教学上常见的坑：外推边界在面元上的连续极限是
**Robin 条件** `J = Dφ/(2.13D)`（对应 `B tan(Ba/2)=1/d`），而教科书
`B = π/(a+2d)` 是小曲率近似。本服务的解析参考默认给与离散严格一致的
Robin 精确根（`physics.geometric_buckling(..., approximate=True)`
可取教科书近似）；对常用基准（Ba 很小）两者差 ~1e-4 量级。

## HTTP 接口（JSON）

工况：
- `POST /cases` 新建（物理校验不过返回 422，`details[].field` 逐字段指错）
- `GET /cases` / `GET /cases/{id}` 列表 / 查询
- `PATCH /cases/{id}` 改名或改某一区（除改名外生成新版本，非法改动被拒且不落版本）
- `DELETE /cases/{id}`
- `GET /cases/{id}/versions`
- `POST /cases/{id}/solve` body `{"mode":"cold"|"hot", "settings"?, "target_total_fission"?}`
  冷/热求解并存档；热启动自动取上一版最近的收敛通量+k；达到 max_iter
  未收敛返回 409，附 `iterations / k / k_residual / flux_residual`，不留结果。
- `GET /cases/{id}/results?version=` / `GET /results/{rid}`

燃耗（异步历程）：
- `POST /cases/{id}/burnups` body
  `{"steps": [天, ...], "version"?, "note"?}` → 202 + 历程号。
  锁定指定（缺省当前）参数版本的快照，后台推进；单段 1–500 步，
  历程累计同样封顶 500 步。
- `GET /cases/{id}/burnups` / `GET /burnups/{id}`：进度——
  `status`（queued/running/completed/cancelled/interrupted/exhausted/
  failed）、`steps_completed`、`burnup_time_days`、`current_k`。
- `POST /burnups/{id}/advance` body `{"steps": [...]}`：从最后一个
  已完成时间点接着往后推（分段推进；推进中返回 409）。
- `POST /burnups/{id}/cancel`：取消当前段；已完成的点保留，
  未完成的步不写入。
- `GET /burnups/{id}/points`：时间点摘要列表（步号、燃耗时间、k、
  各区剩余份额）。
- `GET /burnups/{id}/points/{i}`：单个时间点的完整存档——k、通量、
  各区剩余易裂变份额、各区反应率与两端泄漏、该点的中子平衡残差
  （仍要求 < 1e-8）。

临界搜索（异步）：
- `POST /cases/{id}/searches` body
  `{"region_index", "parameter":"thickness"|"nu_sigma_f", "lower","upper","max_steps"}`
  → 202 + 作业号。作业内嵌提交时刻的参数版本快照。
- `GET /jobs?case_id=` / `GET /jobs/{id}`：`status`（queued/running/
  converged/unconverged/rejected/cancelled/failed/interrupted）、
  `steps_taken`、`current_bracket`、`current_k`、`endpoint_k`、
  `root_value`、`k_at_root`、`result_id`。
- `POST /jobs/{id}/cancel`：置取消标志，工作线程在下一步评估前退出，
  终态 cancelled，不写结果。
- 两端 k−1 同号 → `rejected` 且回报 `endpoint_k`；
  收敛要求代回 |k−1| < 1e-6；步数耗尽 → `unconverged`，回报最后区间与残差。
- 同一工况可并发挂多个作业；工况随后被改/被删，作业仍只认提交时的版本，
  临界点解归档到该（被锁定的）版本下。

## 持久化与容器

`DIFFUSION_DATA_DIR`（默认 `/data`）下 `cases/ results/ jobs/ burnups/
burnup_points/` 五个目录，每个对象一个 JSON 文件，临时文件 +
`os.replace` 原子落盘，直接挂卷即可。服务重启时仍在 queued/running 的
作业与燃耗历程标为 `interrupted`（不自动重跑，避免参数语义漂移）；
其快照保留可查，燃耗历程可从最后一个已完成时间点续推。
